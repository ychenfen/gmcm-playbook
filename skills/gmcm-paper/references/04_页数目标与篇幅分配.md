# 页数目标与篇幅分配

## 硬指标

| 项目 | 本队要求 | 依据：2025 年 21 篇优秀论文 |
|---|---|---|
| 正文页数（摘要页起，到参考文献前一页止，含摘要和目录） | **目标 55 页，不得少于 45 页**；超过 70 页要逐节自查有没有凑数 | 中位 55，四分之一分位 40.5，四分之三分位 67.5，范围 34–101 |
| 全文页数（含参考文献、附录） | 65–85 页 | 中位 76，范围 46–182 |
| 图 | 不少于 20 张，目标 30 张左右（其中过程图 5–8 张） | 中位 30，范围 9–107 |
| 表 | 不少于 8 张，目标 12 张左右 | 中位 12，范围 2–29 |
| 编号公式 | 不少于 40 个 | 中位 67；有些论文把公式做成图片，统计不到，只作参考 |

附件2 没有规定页数上限，只要求摘要一般不超过两页。上面的目标是对照优秀论文定的，不是官方规定。页数本身不加分，但正文不到 40 页，通常说明建模过程写得太简略、检验不够。

统计方法：用 `工具/page_budget.py` 对 2025 年优秀论文选里 A–F 题的 21 篇 PDF 逐篇统计。「图」「表」按行首的图题、表题编号去重计数，公式按行尾的编号计数。优秀论文选没有标明奖项等级，这组数反映的是「能进优秀论文选」的篇幅，不是一等奖的门槛。

每题只有 2–5 篇，样本小，看个量级就行，统一按上面的硬指标执行。

## 55 页怎么分

以 3 个问题为例（`python3 工具/page_budget.py 论文.pdf --questions 3` 会按你们的问题数自动算）：

| 部分 | 页数 | 写什么 |
|---|---|---|
| 摘要 | 2 | 每问一段：方法 + 具体结果数字 |
| 问题重述与问题分析 | 4 | 问题分析里放技术路线图（过程图 A） |
| 模型假设与符号说明 | 2 | 每条假设写理由；符号按类分组 |
| 数据预处理（有数据的题） | 2–3 | 预处理流程图（过程图 D）、清洗前后对比 |
| 问题一 | 11–12 | 见 `05_建模由浅入深写法.md`，后面的问题一般更难，页数递增 |
| 问题二 | 13–14 | |
| 问题三 | 15–16 | |
| 模型检验与灵敏度分析（可分散到各问） | 3 | 参数扰动、鲁棒性、与强基线对比 |
| 模型评价与推广 | 2 | 优点、局限（写具体条件）、推广方向 |
| 结论 | 1 | |

## 页数从哪来：该写的写足，不该凑的别凑

应该写足的（评委看这些打分）：

- 每个模型的推导过程，不跳步，公式编号；
- 为什么选这个模型、为什么要从基础模型升级（用数据说明上一级的不足）；
- 求解算法：伪代码或流程图、复杂度、参数怎么定；
- 结果：强基线对比表、关键结果图、对结果的解释（为什么这样，而不只是是什么）；
- 检验：误差分析、灵敏度、鲁棒性、小规模精确解或下界对照；
- 局限：在什么条件下模型不成立。

不要用来凑页数的（2025 优秀论文里出现过，容易被挑）：

- 教科书原理介绍（遗传算法、模拟退火、神经网络的通用流程图和原理大段抄写）；
- 被弃用方法的大量过程图；
- 同一组数据既画图又列表又画雷达图；
- 大段代码放正文（代码放附录，正文只放伪代码）；
- 大号图片、大量空白。
