# 过程图与作图规范

论文里的图分两类：过程图（技术路线、流程、模型结构）说明「怎么做的」，数据图（对比、灵敏度、收敛、检验）说明「做得怎么样」。按 30 张左右的目标，一般过程图 5–8 张，其余是数据图。

## 一、过程图模板（`过程图模板/`）

六张 TikZ 模板，每张都编译好了 PDF 和 PNG，可以先看效果。框里的文字都是示例，要换成你们自己的方法、数字和公式编号。

| 模板 | 放在哪 | 回答什么 |
|---|---|---|
| 图A 技术路线图 | 问题分析末尾，全文第一张图 | 全文分几问、每问用什么模型、问题之间怎么传递、怎么由浅入深 |
| 图B 由浅入深阶梯 | 每问「模型建立」开头，或全文模型体系处 | 从基础模型到最终模型每升一级放松了什么假设、为什么升、效果如何 |
| 图C 算法流程图 | 模型求解小节，紧挨伪代码 | 算法怎么开始、每轮做什么、何时停；本文改进的是哪一步 |
| 图D 数据预处理流程 | 数据预处理小节开头 | 每步用什么方法、每步后还剩多少样本 |
| 图E 变量影响关系图 | 机理类题目的问题分析或模型建立 | 状态变量、控制变量、外部输入之间谁影响谁、正负向、反馈回路 |
| 图F 双层模型结构 | 优化类题目的模型建立 | 上下两层各决定什么、层间传递什么、怎样迭代收敛 |

### 怎么编译

`procstyle.tex` 是公共样式，必须和模板放在同一个文件夹。

```
cd 过程图模板
latexmk -xelatex 图A_技术路线图.tex
```

- **用 LaTeX 写论文**：`\includegraphics[width=\textwidth]{图A_技术路线图.pdf}`，模板宽度都控制在 150 mm 以内，插入后基本不缩放。
- **用 Word 写论文**：编译出 PDF 后插入 PDF 或 PNG。PNG 可以用 `pdftoppm -r 300 -png -singlefile 图A_技术路线图.pdf 图A` 导出。
- **不会 TikZ**：可以用 draw.io、Visio 或 PPT 按同样的版式画，遵守下面的规则。

### 过程图的规则

1. **每个框写「做什么 + 得到什么」**，最好带一个数字，比如「多元线性回归（基线，R² = 0.71）」。只写「建立模型」「求解模型」这类空框，等于没画。
2. **只画自己的流程。** 教科书式的遗传算法、模拟退火、神经网络原理图不要画，评委见得太多，也体现不出你们的工作量。2025 年有一篇 34 张图的论文就因此被挑出装饰图凑页数。
3. **本文的核心改进用强调色（橙框）标出来**，全图只标一到两处。
4. **箭头方向一致**：主流程从上到下或从左到右；问题间的传递用虚线，并在箭头旁写传递的量。
5. **公式和图对应**：机理图、结构图里的箭头旁写对应的公式编号，读者可以在正文和图之间来回查。
6. **字号不小于正文五号的八成，宽度不超过版心（150 mm）。** 太宽的图插进去会被整体缩小，字就看不清了。
7. **颜色只做辅助。** 黑白打印时，靠框的形状（圆角、方框、平行四边形、菱形）、线型（实线、虚线）和文字也能分清，不能只靠颜色区分。
8. **全文统一样式**：所有过程图共用 `procstyle.tex`，改颜色、字号只改这一个文件。

## 二、数据图（`工具/figstyle.py` + `作图示例/`）

`工具/fig_examples.py` 给出 7 类常用数据图的画法，数据是随机生成的演示数据，**不能用在论文里**：

| 示例 | 用途 |
|---|---|
| 图1 由浅入深逐层升级 | 每升一级误差降多少、代价增多少，是由浅入深最直接的证据 |
| 图2 方法对比 | 本文方法对强基线，基线用灰色，本文用蓝色 |
| 图3 单参数灵敏度 | 参数扫描 + 波动带 + 选定值 |
| 图4 双参数热力图 | 两个参数同时变时，好的区域在哪、有多宽 |
| 图5 收敛曲线与下界 | 收敛情况、离下界还差多少 |
| 图6 小多图 | 逐个对象检验，同一坐标轴 |
| 图7 预测实测与残差 | 有没有系统偏差、误差多大 |

自己作图时，在脚本开头 `from figstyle import plt, C, GRAY, FULL, HALF, save`，字体、字号、配色、导出格式就全文一致了。Mac 上需要 `pip install fonttools`，否则中文会变成特粗宋体。

数据图的规则：

- 每张图只回答一个问题，图题写结论，比如「本文方法在 4 个场景下成本均低于基线 9%–23%」，不要只写「成本对比图」。
- 不用双纵轴；量纲不同就分成子图。
- 不画雷达图、3D 饼图、3D 柱状图。
- 量级差太大的数据不要画在同一坐标轴上，改用对数轴或分面板。
- 图里的数字和正文、表格必须一致，并且都由脚本从结果文件生成，不要手抄。
- 图题放在图下方，表题放在表上方；正文里每张图都要引用并解释，不能只放图不说话。
